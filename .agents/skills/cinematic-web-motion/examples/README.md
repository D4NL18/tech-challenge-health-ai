# Examples (150 standalone HTML demos)

Open any file in a browser (CDN needed only where Libs says GSAP/three). All handle `prefers-reduced-motion`.

The catalogue lives in category files to save tokens: see `INDEX.md` and `index/<category>.md`. Each category lists number, file, one-line effect and libs. 70–150 were QA'd with Playwright (Edge headless): console errors, 390px overflow, scroll screenshots.
